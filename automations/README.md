# Automations

Recurring agent workflows — the kind that run on a schedule or trigger rather than on demand.

The difference between a skill and an automation:

- **Skill** — you invoke it when you need it. "Run the ten-second test on this page."
- **Automation** — it runs itself. "Every Friday, audit the week's work and post a summary to Slack."

## What's here

Automations are added as they're proven out. Each one includes:

- A schedule or trigger definition
- The skill(s) it calls
- The delivery target (Slack channel, doc, email, etc.)
- The approval gates that apply

## Status

This folder is being built out. Skills come first — automations are just scheduled skills with a delivery target bolted on.
