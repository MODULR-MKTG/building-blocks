# Service Stack

The MODULR product stack — three tiers, one ladder. See [DIY DWY DFY Model](diy-dwy-dfy-model.md) for the canonical framing.

```
┌─ DIY ───────────────────────────── ★ self-serve ─┐
│ [MODULR Marketplace](modulr-marketplace.md)                            │
│ Claude plugins + skills (MODULR IP as tools)      │
│ In development                                    │
└───────────────────────────────────────────────────┘
              ↓
┌─ DWY ──────────────────────────────── $2,000 ─────┐
│ [Strategy Workshop and Audit](strategy-workshop-and-audit.md)                   │
│ Workshop + audit of the client's email program    │
│ Intake path into the retainer                     │
└───────────────────────────────────────────────────┘
              ↓
┌─ DFY ★ HEADLINE PRODUCT ───────── $7,000/month ───┐
│ [Email Consulting](email-consulting.md)                              │
│ Ongoing consulting retainer                       │
│ Founder-led businesses with real email upside     │
└───────────────────────────────────────────────────┘
```

**Sidecar (different ICP):**
[Find Your Authority Sprint](find-your-authority-sprint.md) — $1,500. For early-stage brands building authority who are not yet ready for DWY/DFY.
