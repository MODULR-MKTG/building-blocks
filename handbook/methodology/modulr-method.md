# MODULR Method

The core branded IP. Six elements that every revenue-driving email needs. Sometimes taught as **BMODULR** ("Be MODULR") when leading with Big Idea.

```
B → BIG IDEA     What the newsletter is actually about 
M → MESSAGE     The hook that grabs attention (≤15 words)
O → OPINION     Your POV that separates you
D → DATA        Proof that builds credibility (specific numbers)
U → UPSIDE      The payoff they actually want (visualizable)
L → LINK        Clear CTA (one action, no confusion)
R → REVENUE     How this email connects to money
```

## BMODULR (extended)
- **B** — Big Idea (one clear, compelling point)
- **M** — Message/Hook
- **O** — Opinion
- **D** — Data
- **U** — Upside
- **L** — Link/CTA
- **R** — Path to Revenue (qualifier, not scored in v1)

## Pitched as
"Six elements. Every email. Every time. When all six work together, your emails stop being background noise and start making money."
