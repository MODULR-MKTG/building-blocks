# Client Constellation

Niching down doesn't limit opportunity — it attracts an entire constellation of adjacent industries. Keep the **service** the same; let adjacent industries flow in.

## MODULR's constellation
Core: **Creator educators**

| Core | Adjacent |
|------|----------|
| Creator educators (courses) | Online coaches |
| | Membership site owners |
| | Digital product creators |
| | Newsletter operators |
| | Community builders |
| | SaaS founders with educational content |
| | Authors with backend products |
| | Consultants productizing expertise |
| | Workshop / event creators |
| | Certification program owners |

## Shared traits
All share:
- Audience-building via content
- Email as primary revenue channel
- Info-product business model
- Need to convert attention into sales without being "salesy"
